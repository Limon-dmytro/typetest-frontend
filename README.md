# TypeTest - Frontend

A typing speed trainer built with **Svelte + Vite**.

![TypeTest Preview](image.png)

## Features

- modern home page design
- typing trainer with timer
- character highlighting for correct and incorrect input
- progress tracking
- WPM, accuracy, and error calculation
- custom UI component library

## Tech Stack

- Svelte
- Vite
- JavaScript
- svelte-spa-router

## Getting Started

```bash
npm install
npm run dev
